# WireWOL PC

집에 있는 PC를 다른 컴퓨터(노트북 등)에서 리모컨처럼 켜고(Wake-on-LAN), 끄고(원격 종료), WireGuard VPN을 켰다 끌 수 있게 해주는 윈도우 앱입니다.

[WireWOL](https://github.com/huny4daniel/wire-wol_v) 안드로이드 앱의 PC판으로, 기능과 동작 방식은 안드로이드 앱과 같습니다.

## 준비물

- **켜고 끌 PC 쪽**: WireWOL 컴패니언(`WireWOL_vX.Y.Z.exe`, [wire-wol_v 릴리즈](https://github.com/huny4daniel/wire-wol_v/releases))이 설치되어 있어야 합니다. 설치 방법은 wire-wol_v의 README를 참고하세요. 트레이 아이콘 → **연결 정보 보기**로 QR을 띄울 수 있습니다.
- **이 앱을 쓰는 컴퓨터 쪽**: 이 앱 하나면 됩니다. WireGuard가 앱에 내장되어 있어 공식 WireGuard 앱을 따로 설치할 필요가 없습니다.

## 설치

1. [Releases](https://github.com/huny4daniel/wire-wol-pc_v/releases) 페이지에서 최신 버전의 `WireWOLPC_vX.Y.Z.exe`를 내려받아 실행합니다.
2. 실행할 때마다 UAC(관리자 권한) 확인 창이 뜹니다 — 내장 WireGuard 터널을 켜고 끄려면 관리자 권한이 필요합니다.
3. **설정** → **PC 등록**에서 입력 방법을 고릅니다.
   - **웹캠으로 스캔** — PC 화면에 띄운 연결 정보 QR을 웹캠으로 찍습니다.
   - **이미지 파일에서 QR 불러오기** — QR을 캡처해둔 이미지에서 바로 읽습니다.
   - **직접 입력** — QR 없이 PC 주소/포트/토큰/MAC을 손으로 입력합니다.
4. **‹ 뒤로**를 눌러 메인 화면으로 돌아오면 상태 카드에 PC 상태, 연결 대상, MAC 주소가 표시됩니다.

## 사용 방법

### 상태 카드

창이 떠 있는 동안 5초마다 PC가 응답하는지 확인해 **켜짐 / 꺼짐 / 응답 없음**을 보여줍니다(창을 최소화하면 확인을 멈추고, 다시 열면 이어갑니다).

- 집 밖에서 와이어가드가 꺼져 있어 PC에 닿지 않으면 "꺼짐"으로 단정하지 않고 "와이어가드를 켜야 확인됩니다"라고 구분해 표시합니다.
- 연결 대상, MAC 주소, WireGuard 연결 상태, 걸려 있는 종료 예약도 함께 표시됩니다.

### PC 켜기

저장된 MAC 주소로 매직 패킷을 보냅니다.

- 같은 네트워크에 있거나 WireGuard로 집 네트워크에 연결되어 있어야 패킷이 도달합니다.
- WireGuard 설정이 있고 PC에 직접 닿지 않으면(집 밖이면) **와이어가드를 자동으로 켠 뒤** 신호를 보냅니다.
- 누른 뒤 처음 15초는 1초 간격, 이후 5초 간격으로 PC 상태를 재확인합니다.
- "원격 WOL"을 설정해두면 공유기를 통해서도 켜기 신호를 보냅니다.

### PC 끄기 / 예약

- **PC 끄기**: 확인 후 종료 명령을 보내며, 10초 유예 동안 창 아래 알림의 **취소**로 되돌릴 수 있습니다.
- **예약**: 몇 시간 몇 분 뒤에 끌지 고릅니다(최대 23시간 59분). 상태 카드의 예약 표시를 클릭하면 취소됩니다. 새로 예약하면 기존 예약을 덮어씁니다.
- PC가 응답하지 않으면 절전 상태일 수 있어 깨우기 신호를 보낸 뒤 최대 30초간 기다렸다가 한 번 더 시도합니다.
- 와이어가드를 켠 상태에서 끄기에 성공하면, PC가 실제로 꺼진 것을 확인한 뒤 와이어가드도 자동으로 꺼집니다(종료 취소, 와이어가드·PC 켜기 버튼을 직접 누르면 자동 끄기는 해제).

### 와이어가드 켜기 / 끄기

집 밖에서도 PC와 같은 네트워크에 있는 것처럼 통신하기 위한 VPN 스위치입니다. 누른 상태를 그대로 유지하며, 창을 최소화해도 꺼지지 않습니다. **창을 닫아 앱을 끝내면 와이어가드도 함께 꺼집니다.**

터널은 **등록한 PC가 있는 대역(/24)으로 가는 통신만** 맡습니다. WireGuard 설정의 AllowedIPs·DNS는 무시하므로 이 PC의 다른 인터넷 통신은 터널을 거치지 않고, 터널이 막혀도 인터넷은 끊기지 않습니다. 이 PC가 PC와 같은 네트워크(집 안)에 있으면 PC가 꺼져 있어도 와이어가드를 켜지 않고, 켜 둔 채 집에 들어오면 자동으로 끕니다.

먼저 **설정 → WireGuard 설정 등록**에서 공유기 등이 만들어준 WireGuard 설정을 등록하세요(웹캠 QR 스캔 / QR 이미지 / `.conf` 파일 불러오기).

## 설정 화면

- **PC 등록** (필수) — 연결 정보와 MAC 주소. QR의 MAC이 잘못된 경우(랜카드가 여러 개) **직접 입력**에서 MAC만 고치면 됩니다.
- **WireGuard 설정 등록** (선택) — 집 밖에서 접속할 때만 필요합니다.
- **원격(외부망) WOL 설정** (선택) — 공유기(iptime 등)의 원격 깨우기 기능으로 와이어가드 없이도 PC를 켭니다. 공유기 관리자 계정이 저장되니 개인 PC에서만 설정하세요.
- **PC 켜기 후 자동 종료** (선택, 기본값 사용 안 함) — 원격으로 켜두고 깜빡 잊고 못 끄는 것을 막아줍니다. 사용으로 켜고 시간을 정해두면, PC 켜기로 켠 PC가 켜진 것이 확인되는 순간 그 시간 뒤로 종료 예약이 자동으로 걸립니다(이미 걸어둔 예약은 덮어쓰지 않음, 창을 최소화했다가 10분 안에 다시 열면 이어서 확인).
- **설정 내보내기 / 불러오기** — 위 설정을 전부 비밀번호로 암호화한 파일 하나(`wirewol_settings.json`)로 저장하거나 불러와 그대로 복원합니다. WireWOL 안드로이드 앱과 같은 파일 형식이라 폰↔PC로 설정을 옮길 수 있습니다. 불러오면 지금 설정은 파일의 설정으로 바뀝니다.
- **저장된 정보 초기화** — 위 설정을 모두 지웁니다.

## 참고 사항

- 설정(토큰, WireGuard 개인키, 공유기 비밀번호)은 윈도우 계정에 묶인 DPAPI로 암호화해 `%LOCALAPPDATA%\WireWOL PC\`에 저장됩니다.
- 내장 WireGuard는 켤 때 `WireGuardTunnel$wirewolpc` 윈도우 서비스를 만들고 끌 때 지웁니다. 실행 파일은 `%ProgramData%\WireWOL PC\`(관리자만 접근 가능)에 둡니다.
- 컴패니언과는 평범한 http로 통신합니다(같은 네트워크 또는 WireGuard 터널 안이라고 가정). 컴패니언 포트를 인터넷에 직접 노출하지 마세요.

## 소스에서 빌드하기

```
pip install -r requirements.txt
pwsh -File scripts/build_tunnel.ps1   # vendor/amd64/에 tunnel.dll, wireguard.dll, 서비스 호스트 생성
python wirewolpc.pyw
```

`build_tunnel.ps1`은 Go와 wireguard-nt를 자동으로 받지만, cgo용 gcc(mingw-w64)는 PATH에 있어야 합니다.

버전 태그(`v*`)를 푸시하면 GitHub Actions가 exe를 빌드해 릴리즈로 올립니다(`.github/workflows/release.yml`).
